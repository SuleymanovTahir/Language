# Голоса приложения

- **Microsoft Edge Neural** — облачная озвучка немецкого, английского и французского без аккаунта Azure и ключа. Серверный маршрут использует неофициальный пакет `edge-tts`; доступность и голоса могут измениться.
- **Kokoro** — синтез английского и французского в браузере. При первом включении загружается модель примерно на 100 МБ; после этого браузер кэширует её. Голос и текст остаются на устройстве.
- **ElevenLabs** — серверная озвучка; ключ хранится только в переменной среды Vercel. Использовать могут вошедшие в аккаунт пользователи. Выбрать стандартный голос George или указать Voice ID из своего аккаунта.
- **Azure Speech** — дополнительная интеграция для немецкого, английского и французского. Требует `AZURE_SPEECH_KEY` и `AZURE_SPEECH_REGION`; без этого приложения Azure не подключается.
- **Голос устройства** — системный синтезатор браузера.

## Переменные Vercel

Добавлять только в Settings → Environment Variables, не в клиентский код и не в чат:

```text
ELEVENLABS_API_KEY=
AZURE_SPEECH_KEY=
AZURE_SPEECH_REGION=
```

После добавления переменных Vercel нужно создать новое production-развёртывание. Облачные маршруты требуют входа в аккаунт. Вызовы ограничены 2 000 символами.

## Источники и лицензии

- [edge-tts](https://github.com/rany2/edge-tts) — community-пакет для онлайн-службы Microsoft Edge; это не Azure Speech API.
- [Kokoro](https://github.com/hexgrad/kokoro) — модель с лицензией Apache-2.0.
- [Kokoro.js](https://github.com/hexgrad/kokoro/blob/main/kokoro.js/README.md) — запуск модели через Transformers.js в браузере.
- [ElevenLabs: синтез речи](https://elevenlabs.io/docs/api-reference/text-to-speech/convert) — API, модель и Voice ID.
- [Azure Speech: список голосов](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=text-to-speech).
